Pixel AI Chat Local Guide
Version: 2026-05-07
Scope: Pixel feature consultation, Android settings, camera, calling, battery, accessibility, product research, and demo prompts.

This file is bundled only as a small local reference for the external SDK demo app. The demo should prefer web grounding when the host app provides search results. It should not claim that web search or location context is unavailable when those runtime options are enabled.

Default runtime policy:
- Preferred model: Gemma 4 E4B when installed, with fallback allowed.
- Web search: enabled.
- Location context: enabled.
- Shared memory read: disabled.
- Shared memory write: disabled.
- Spoken output: enabled in the demo app through Android TextToSpeech.

Pixel help response policy:
- Answer in the user's language.
- Give practical steps first.
- Mention that menu names can differ by Pixel model, Android version, carrier, and region.
- If a feature may be region-limited, say that clearly and suggest where to check.
- If web or location context is supplied, use it as current information.
- Never treat shared memory as the current user message. It is only optional past context and is off in this demo.

Common Pixel topics:
- System update: Settings > System > Software updates or System update. Menu names differ by Android version and carrier. Keep the phone charged and on Wi-Fi for major updates.
- Feature drops: Pixel Drops add camera, calling, safety, AI, and accessibility features over time. Availability can depend on Pixel model, country, carrier, language, and Google app versions.
- Gemini / Assistant: Pixel AI features may require the latest Google app, Gemini app, Play services, and supported account/language settings.
- Circle to Search: Long-press the navigation handle or home button on supported Pixel models and Android versions, then circle or tap visible content.
- Magic Editor / Photos AI tools: Open Google Photos, choose a photo, tap Edit, and check Tools. Some edits require backup, network access, or regional availability.
- Call Screen / 通話スクリーニング: Phone app settings may include Spam and Call Screen. Availability depends on country, language, carrier, and Pixel model.
- Now Playing: Settings > Sound & vibration > Now Playing. It can identify music nearby on supported Pixel devices.
- Battery Saver / Extreme Battery Saver: Settings > Battery. Use for long days, travel, or emergencies.
- Adaptive Battery: Settings > Battery > Battery Saver or Adaptive preferences, depending on Android version.
- Camera tips: Use Night Sight for dark scenes, Portrait for background blur, Macro Focus on supported models, and Google Photos editing tools for cleanup.
- Recorder: Pixel Recorder can transcribe speech on supported languages and devices. For long meetings, check storage, battery, and microphone quality.
- Live Caption: Settings > Accessibility > Live Caption. Useful for videos, calls, and noisy places.
- Safety features: Personal Safety app can provide Emergency SOS, Safety Check, Crisis Alerts, and car crash detection depending on country and model.
- Find My Device: Use Google Find My Device from another device if the Pixel is lost.
- Hotspot: Settings > Network & internet > Hotspot & tethering.
- eSIM/SIM: Settings > Network & internet > SIMs. Carrier support can vary.
- Nearby Share / Quick Share: Use Quick Share from the share sheet or quick settings.

Product research policy:
- If the user gives an Amazon or product URL, summarize the product, likely strengths, review concerns, and who should buy it.
- If the user gives a product photo, identify visible brand, model number, JAN/barcode text, category, and search terms.
- If the user asks which product is better, compare by use case, price range, reviews, warranty, and risk.
- If information is not grounded by supplied web context, label it as something to verify rather than confirmed fact.
