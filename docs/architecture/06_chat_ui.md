# チャット UI / UX 設計

## UX コンセプト

### キーワード

- 親しみやすい
- 先進的
- 安心できる
- ローカル実行がわかる

## 主要画面

### 1. オンボーディング

- オンデバイス実行であることを説明
- オフライン利用可能を明示
- 推奨モデルを端末性能に応じて提案
- 必要ストレージと推定速度を表示

### 2. チャット画面

- トークン逐次表示
- 停止ボタン
- モデルバッジ
- adapter / persona 切替
- ローカル実行中インジケータ

### 3. モデル管理画面

- 利用可能モデル一覧
- ダウンロード進捗
- 容量と推奨 RAM
- 更新可否
- 削除候補提示

### 4. 開発者コンソール

- 接続済みアプリ一覧
- SDK 利用状況
- adapter 一覧
- ローカル API 状態

## UI スタイル指針

- 暖かい配色に無機質すぎない未来感を加える
- モデル情報はカード UI で明確化
- 推論中はタイピング感ではなく処理の透明性を重視
- 速度よりも安心感と理解可能性を優先する

## 実装指針

- ストリーミングは末尾のみを高頻度更新
- 長文時も再描画範囲を限定
- エラー時は代替モデル提案を同じ文脈で出す
- オフライン時も主要導線が切れないようにする

## 主要状態

- 初期未設定
- モデル未導入
- ダウンロード中
- 利用可能
- 推論中
- 停止中
- エラー

## 成功基準

- 初回起動で何をダウンロードすべきか迷わない
- 推論中に端末内処理であることが明確
- 他アプリ連携があっても単体アプリとして魅力的に使える
