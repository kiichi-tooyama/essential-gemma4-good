# Kaggle Form Fields

## Title

Essential Field Companion: Private Gemma 4 on Android

## Short Description

An Android local-first assistant powered by Gemma 4 LiteRT-LM through Google AI
Edge. It routes tasks between local reasoning, live speech recognition, Whisper
meeting transcription, MeloTTS speech output, optional web/location grounding,
shared memory, and SDK-style access from other apps, shown with a Pixel feature
chat demo app.

## Tags

Gemma 4, LiteRT, Google AI Edge, Android, Cactus, llama.cpp, on-device AI,
local-first, multimodal, voice, accessibility, digital equity, resilience

## One-Sentence Pitch

Essential turns an Android phone into a private Gemma 4 field assistant and
local AI API that routes text, voice, photos, meetings, web grounding, and speech
output through the best available local model path, including requests from
other Android apps.

## Track Award Positioning

If Kaggle allows only one selected track, choose LiteRT because it is the
strongest demonstrated implementation path. In the writeup and video, also state
the fit for Cactus and llama.cpp.
