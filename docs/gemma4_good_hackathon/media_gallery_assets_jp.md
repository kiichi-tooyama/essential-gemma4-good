# Media Gallery 準備

Kaggle Writeup には cover image が必須。動画も Media Gallery に付ける。

## Cover Image 案

比率: 16:9 または横長。

入れる文字:

```text
Essential Field Companion
Private Gemma 4 on Android
```

画像内容:

- Android phone screen.
- Model routing diagram: Gemma 4 LiteRT-LM, SpeechRecognizer, Whisper, MeloTTS, Web/Location.
- Field work feel: classroom, clinic, volunteer, disaster-support, or rural setting。
- 暗すぎない。実アプリ画面が分かる方がよい。

画像生成プロンプト:

```text
A clean editorial hackathon cover image for an Android app called "Essential Field Companion". Show a real-looking Android phone running a private AI assistant, with small labeled routing lines to "Gemma 4 LiteRT-LM", "SpeechRecognizer", "Whisper", "MeloTTS", and "Web / Location optional". The setting suggests field work and digital equity: a simple desk with notes, a community support map, and a phone. Professional, bright, realistic, not futuristic, not dark, no fake company logos. Include readable title text: "Essential Field Companion" and subtitle "Private Gemma 4 on Android". 16:9.
```

## スクリーンショット

最低4枚:

1. Model Management: Gemma 4 LiteRT-LM E2B/E4B が見える。
2. Chat: Web sources または location-aware answer が見える。
3. Essential Live: voice mode が見える。
4. Meeting Assistant: summary / TODO / translation / mind map が見える。
