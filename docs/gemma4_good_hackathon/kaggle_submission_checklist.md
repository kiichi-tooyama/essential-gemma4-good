# Kaggle Submission Checklist

## Required Items

- Kaggle Writeup under 1,500 words: `docs/gemma4_good_hackathon/kaggle_writeup.md`
- Public YouTube video, 3 minutes or less.
- Public code repository link.
- Live demo link or files. For this Android project, attach an APK or link to a
  GitHub Release APK in addition to the repository.
- Media Gallery cover image and demo screenshots.

## Track Strategy

- Primary target: Special Technology Track, LiteRT.
- Secondary impact framing: Digital Equity & Inclusivity.
- Main Track is a stretch target if the final video clearly proves the API,
  Live voice, meeting assistant, and polished product flow.
- Do not emphasize Cactus unless model routing between multiple model families
  is clearly shown in the final video and writeup.

## APK Note

An APK is useful as the Live Demo file, but it is not a replacement for the
required Kaggle Writeup, public video, and public code repository. Final
submission should include both the repository and an installable APK or release
file if allowed by the Kaggle attachment UI.
